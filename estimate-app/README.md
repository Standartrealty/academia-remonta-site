# Смета ремонта

Приложение `/smeta`: объекты, замеры, чек-лист работ, расчёт, PDF, Excel и JSON. Next.js со статическим экспортом; сервер и регистрация не нужны.

## Сборка

Node.js >=22.12; pnpm 11.25.0. Выполните `pnpm install`, затем `pnpm dev` для разработки или `pnpm build` для публикации. Build копирует экспорт в `../smeta`, service worker в `../smeta-sw.js`. Публикуйте вместе с существующим сайтом. После изменения исходников пересоберите экспорт.

## Работа

Создайте объект, заполните адрес, добавьте помещения и размеры. Последовательно проверьте разделы работ каждого помещения. Автоматические объёмы можно заменить вручную. Перед выгрузкой введите актуальные цены работ и материалов.

Стартовые расценки — примеры. Материалы с нулевой ценой не включены. Согласование — внутренняя отметка прораба.

Данные сохраняются в IndexedDB только на текущем устройстве и в текущем браузере. Регулярно скачивайте резервную копию JSON в настройках. Восстановление добавляет объекты, совпадения импортируются копиями. Очистка данных браузера удаляет объекты. Синхронизации между устройствами нет.

После первого открытия и надписи «Готово к работе офлайн» приложение работает без сети, включая экспорт. На iPhone: Safari → Поделиться → На экран «Домой». На Android: установка через меню браузера.

PDF использует локальный DejaVu Sans, лицензия в public/fonts.
